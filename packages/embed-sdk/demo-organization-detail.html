Organization Detail

Detail page for a single organization from the directory — photo, address, pastor, and Mass schedule.

<next-organization-detail>
Reads its ID from the URL: this page expects ?id=<Congregation_ID> in its own address bar (e.g. reached by clicking a result on the Organization Directory demo). Try appending ?id=1 to this page's URL directly.

Widget CodeAdd this to any page where you want this widget

<!-- Use the widget -->
<next-organization-detail></next-organization-detail>

<!-- Listen to events -->
<script>
  const widget = document.querySelector("next-organization-detail");
  widget.addEventListener("organizationDetailLoaded", (e) => {
    console.log("Loaded:", e.detail);
  });
  widget.addEventListener("organizationDetailError", (e) => {
    console.error("Error:", e.detail);
  });
</script>
